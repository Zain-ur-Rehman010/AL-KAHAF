## Documentation Policy

- Keep docs actionable and current.
- Remove one-off snapshots after they are no longer useful.
- Update references immediately when files are renamed/deleted.
- Keep environment variable names consistent with:
  - `backend/.env.example`
  - `backend/src/server.js`
  - `backend/src/config/config.js`

## If You Are Unsure Where To Look

- Setup problem: `ENV_SETUP_GUIDE.md`
- Runtime/API issue: `backend/README.md` + `QUICK_TEST.md`
- Deployment issue: `guides/CPANEL_DEPLOYMENT_GUIDE.md`
- Frontend integration issue: `guides/FRONTEND_DEPLOYMENT_GUIDE.md`
