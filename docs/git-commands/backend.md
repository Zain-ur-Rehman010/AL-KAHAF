# Branch: `backend`

Backend development branch. Handles Express.js, Sequelize models, controllers, routes, and services.

---

## Commands

### Switch to backend branch
```bash
git checkout backend
```

### Pull latest changes
```bash
git pull origin backend
```

### Push to remote
```bash
git push origin backend
```

### Merge main into backend (to stay up to date)
```bash
git checkout backend
git fetch origin main
git merge origin/main
```
