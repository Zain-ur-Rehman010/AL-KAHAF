# Branch: `frontend`

Frontend development branch. Handles HTML pages, Vanilla JS, Sass/CSS.

---

## Commands

### Switch to frontend branch
```bash
git checkout frontend
```

### Pull latest changes
```bash
git pull origin frontend
```

### Push to remote
```bash
git push origin frontend
```

### Merge main into frontend (to stay up to date)
```bash
git checkout frontend
git fetch origin main
git merge origin/main
```
