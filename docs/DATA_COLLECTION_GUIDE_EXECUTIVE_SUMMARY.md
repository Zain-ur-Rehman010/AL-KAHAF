# AlKahaf Arabic Teaching Academy
## Data Collection Guide - Executive Summary

**Document Version:** 1.0

## Overview

This document outlines the essential data that will be collected through the AlKahaf Learning Management System (LMS) to provide a world-class Arabic learning experience. The platform will serve students worldwide learning Quran, Tajweed, and Arabic language.

---

## 1. Student Information We'll Collect

### Registration (Required)
✅ **Basic Details:**
- Full Name (English & Arabic)
- Email Address (for login)
- Password (secure, minimum 6 characters)
- Phone Number (WhatsApp preferred)
- Country/Region

✅ **Learning Profile:**
- **Arabic Level:**
  - Complete Beginner
  - Elementary (know alphabet)
  - Intermediate (basic reading/writing)
  - Advanced (fluent)

- **Learning Goals (select multiple):**
  - Quran Reading & Tajweed
  - Quran Memorization (Hifz)
  - Conversational Arabic
  - Classical Arabic
  - Modern Standard Arabic
  - Arabic Grammar
  - Arabic for Business
  - Islamic Studies in Arabic

- **Previous Study:**
  - Have you studied Arabic before? Yes/No
  - Can you read Arabic letters? Yes/No

### Optional Information
- Native Language
- Age Group (Under 18, 18-25, 26-35, 36-50, 50+)
- Preferred Learning Time (Morning/Afternoon/Evening)
- Preferred Arabic Dialect (Egyptian, Gulf, Levantine, etc.)

## 3. Course Information We'll Collect

### Course Details (Required)
✅ **Basic Information:**
- Course Title (English & Arabic)
- Short Description (1-2 sentences)
- Full Description (200-500 words)
- Category:
  - Quran & Tajweed
  - Arabic Language (Beginner/Intermediate/Advanced)
  - Arabic Grammar
  - Conversational Arabic
  - Arabic for Kids
  - Islamic Studies
  - Arabic Calligraphy

✅ **Course Structure:**
- **Type:** Pre-recorded / Live Classes / Hybrid
- **Duration:** Total hours, number of weeks
- **Level:** Beginner / Elementary / Intermediate / Advanced

✅ **Course Content:**
- Video Lessons (number, total duration, YouTube links)
- Audio Lessons (for pronunciation practice)
- Downloadable Resources:
  - PDF Workbooks
  - Practice Sheets
  - Arabic Alphabet Charts
  - Tajweed Rules Charts
  - Vocabulary Lists

✅ **Assessments:**
- Quizzes (Yes/No, how many)
- Assignments (Yes/No, how many)
- Practice Exercises

✅ **Modules & Lessons:**
```
Example Structure:
Module 1: Introduction to Tajweed
  - Lesson 1.1: What is Tajweed? (15 min video)
  - Lesson 1.2: Importance of Tajweed (10 min video)
  - Quiz 1: Basics (10 questions)

Module 2: Makharij (Articulation Points)
  - Lesson 2.1: Throat Letters (15 min video + audio)
  - Lesson 2.2: Tongue Letters (20 min video + audio)
  - Assignment 1: Record your pronunciation
```

✅ **Prerequisites & Outcomes:**
- What students need to know before enrolling
- What students will learn by the end

✅ **Pricing:**
- Free Course or Paid Course
- Price (in USD/SAR/EUR)
- Discount options
- Certificate upon completion (Yes/No)
- Minimum completion % for certificate (80-100%)

✅ **Course Media:**
- Thumbnail Image (1280x720 pixels)
- Promotional Video (1-3 minutes, optional)
- Language: Arabic, English, or Bilingual

## 10. Privacy & Security

### Data Protection:
✅ **Security Measures:**
- Passwords encrypted (bcrypt)
- HTTPS/SSL encryption
- Secure JWT authentication
- SQL injection prevention
- XSS protection
- Daily automated backups

✅ **GDPR Compliance:**
- Privacy Policy page
- Cookie consent
- Students can download their data
- Students can delete their account
- Data portability (export to PDF/JSON)

### Access Control:
✅ Role-based permissions (Admin, Instructor, Student)
✅ Students access only enrolled courses
✅ Instructors edit only their courses
✅ Admins have full system access
